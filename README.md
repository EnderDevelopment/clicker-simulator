# Roblox Click Simulator

This project contains scripts for a simple +1 clicking simulator in Roblox. The scripts include a main script for game logic, a script for the click button, and a script for the score display. The project is designed to be easy to set up and use, making it accessible for both beginners and experienced Roblox developers.

## Install

1. Download the project files from the GitHub repository.
2. Open Roblox Studio and create a new place.
3. Place a `TextButton` named `ClickButton` in the workspace.
4. Place a `TextLabel` named `ScoreText` in the workspace.
5. Create a `Folder` named `leaderstats` under each player.
6. Add the scripts to their respective objects as described in the File Structure section.

## Use

1. Run the game in Roblox Studio.
2. Click the `ClickButton` to increase your score.
3. The `ScoreText` will display your current score.
